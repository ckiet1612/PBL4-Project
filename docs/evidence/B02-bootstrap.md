The first fresh verification exposed a local packaging failure: default editable sync produced `__editable__.nexa-0.1.0.pth`, which Homebrew Python 3.12.13 skipped as a hidden `.pth` file, so pytest could not import `nexa`. The final command contract uses frozen `--no-editable` installation and `uv run --no-sync`; this installs the package into `site-packages` and prevents later commands from silently switching the environment back to editable mode.

The CI workflow uses `permissions: contents: read`, contains no secret, service, cache correctness dependency, deployment, publish, migration or `continue-on-error`, and invokes the same frozen install/lint/test/typecheck/build commands verified locally. A GitHub-hosted Actions run remains unverified; the B02 closure condition requires a validated workflow that calls proven commands, not hosted execution. This distinction remains recorded rather than converted into runtime evidence.
